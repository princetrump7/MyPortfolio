🚀 Self-Updating Portfolio Website
Welcome to my personal portfolio! This is a modern, responsive, and dynamic website built to showcase my journey as a Computer Science student and developer.

The standout feature? It talks to GitHub. Instead of manually adding projects, this site uses the GitHub API to automatically fetch and display my latest repositories.

✨ Features
Typewriter Effect: A dynamic hero section that cycles through my roles (Developer, Problem Solver, etc.).

GitHub API Integration: Automatically pulls my most recent projects, descriptions, and primary languages directly from my GitHub profile.

"Show More" Logic: Keeps the UI clean by showing the top 3 projects first, with a smooth staggered animation to reveal more.

Modern Dark UI: A sleek, "frosted glass" navigation bar and neon accent colors.

Responsive Design: Fully optimized for mobile, tablet, and desktop viewing.

Interactive Skills: Visual icons powered by FontAwesome for quick scanning.

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)

Icons: FontAwesome

Typography: Google Fonts (Poppins)

API: GitHub REST API

🚀 How to Use & Customize
If you want to use this template for yourself, follow these steps:

Clone the repo:

Bash
git clone https://github.com/princetrump7/your-repo-name.git
Change the Username: Open index.html and look for the JavaScript constant near the bottom:

JavaScript
const GITHUB_USERNAME = "princetrump7"; // Replace with your username
Update Personal Info: Change the <h1> name and the <p> description in the Header and About sections.

Deploy: Push it to GitHub Pages, Vercel, or Netlify for free hosting!
